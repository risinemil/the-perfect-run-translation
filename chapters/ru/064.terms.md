# Chapter 64 — New Terms

| EN | RU | Notes |
|---|---|---|
| Tête de Chien | Тет-де-Шьен | Promontory near Monaco. French geographic name, transliterate. |
| Place du Casino | Площадь Казино | Famous Monaco landmark. Translate. |
| Monte Carlo (casino) | Монте-Карло | Casino name. Standard Russian transliteration. |
| Jean-Stéphanie | Жан-Стефани | Fictional "sovereign prince" of Monaco. Transliterate. |
| Simon | Симон | Sheriff of Suitestown. French name. |
| Martine | Мартин | Mayor of Suitestown. French female name. |
| Suitestown | Номеровилль | Community name from hotel suites. "Номер" (hotel room) + "вилль" (ville/town). |
| croupier(s) | крупье | Casino staff — the golden-masked clown creatures. Standard Russian loan. |
| pocket dimension | карманное измерение | The Monte Carlo Casino's true nature. Translate. |
| p'tit rital | ритальчик | French slang for Italian person (diminutive). Adapted as diminutive in Russian. |
| rital | ритал | French slang for Italian. Transliterate. |
| The Myth of Sisyphus | «Миф о Сизифе» | Camus book. Standard Russian translation. |
| La Grande Vadrouille | «Большая прогулка» | 1966 French comedy film. Standard Russian title. |
| the boulder | валун | Sisyphean metaphor, key motif. |
| harakiri | харакири | Simon's chosen death. Standard Russian loan. |
| Tony Montana | Тони Монтана | Scarface reference. Transliterate. |
| Pennywise | Пеннивайз | IT clown reference. Standard Russian transliteration. |
